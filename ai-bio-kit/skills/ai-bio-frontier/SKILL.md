# AI×生物学前沿监测

本技能是领域数据层，方法论规则以第二节为准。

## 一、核心资产（references/ 目录）

| 文件 | 用途 |
|---|---|
| `sources.md` | 分级源清单——检索入口白名单 |
| `queries.md` | 七域固定检索查询组——日报的检索骨架 |
| `milestones.md` | 里程碑锚点——判断「新进展是否真的新」的基准 |
| `digest-template.md` | 日报 Markdown 结构模板 |

## 二、规则摘要（方法论详见 rigorous-research）

1. 来源四级：同行评议 > 预印本（标注）> 机构公告（企业声明一律标注「单一来源」）> 权威媒体（仅背景交叉）
2. 模型能力声明核对三要素：指标 / 测试集 / 年份，缺项明示
3. 重大声明双源交叉验证，单源进待核实清单
4. 三类标注：事实（常规）、预印本与单一来源（标注）、「分析：」（推断）
5. 命中后必须回源访问原文；转载媒体只作线索

## 三、日报工作流（五步）

1. **防重复**：目标目录若已存在当日文件（`YYYY-MM-DD.md`），跳过本次任务
2. **检索**：按 `queries.md` 七域查询组逐组执行，窗口默认最近 3 天；每组至少 1 条通用查询 + 1 条限定来源查询；另查横向查询（自主科研系统、重点机构公告）
3. **核对分级**：回源访问、来源分级、三要素核对、双源验证
4. **产出**：按 `digest-template.md` 写 Markdown 日报（只保留有效阅读内容，查询与排除过程不写入正文），存为 `工作台目录/data/digests/YYYY-MM-DD.md`（工作台根目录即 server.py 所在目录）；无重大进展的日子照常产出并如实写明
5. **HTML 阅读版**（可选）：运行 `python3 scripts/digest2html.py <日报.md>`，在同目录生成同名单文件 HTML；脚本自带零改动校验，FAIL 必须修复重跑

## 四、领域判定基线（继承自源项目报告）

- 能力地图与组织层级成反比：分子层最成熟，细胞层次之，个体与生态系统层几乎无能力证明；决定变量是数据基础设施的历史厚度
- 结构预测已在「基准意义上」解决，但限于单体静态结构；复合物、亲和力、构象系综仍有明确缺口
- AI 当前角色是「假设生成器」与「证据集成器」，而非自主「科学发现者」
- 以上为分析性判断（非事实），新证据出现时应在日报「里程碑对照」区讨论，而非默认沿用

## 五、周报变体

每周最后一天可将 7 份日报合并为周报：去重、按七域重组、对照 `milestones.md` 写「本周是否改变锚点格局」综述。格式仍用 `digest-template.md`，标题改「周报」。
