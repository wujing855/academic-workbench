# 豆包适配：当成提示词用

豆包网页版没有规则/技能机制，但有很强的长上下文。用法：

## 一次性的活（跑起来/填 Key）——直接贴

把 `SKILL.md` 全文贴给豆包，然后**一次性把第 0 步的 10 个问题答完**（这样它不用来回追问，一次就能配到位）：

> 请按上面的说明书帮我装。第 0 步的问题我一并回答：
> 1）方向叫【如 清代文献学】；2）我读【本科/硕士/博士】；3）现在是【几年级 / 或哪年入学】；
> 4）学制【N】年；5）领域是【…】；6）最想追踪【期刊或关键词】；7）模型用【阿里云百炼 / DeepSeek / 其它】；
> 8）天气【要 / 不要】；9）PDF 转写【要云端加速 / 只要本地】；10）自动化【要 / 不要】。
> 请一步步带我把工作台跑起来并配好。

豆包会走"第 1 步"往下。装好后这份说明书就没用了，不用留着。

## 周期性的活（每日前沿瞭望/日报）——用定时任务

豆包的"每日任务/定时任务"功能里，把 `ai-bio-kit/skills/ai-bio-frontier/SKILL.md`（换成你领域后的版本）全文贴为任务指令，设定每天早上执行。产出手动存到 `data/frontier/` 即可（豆包不碰你的本地文件，这是它和 WorkBuddy/TRAE 的最大差别）。

## 改代码的活——贴文件 + 说清楚

豆包可以读文件/写文件（客户端版）。让它改 `fetchers.py` 时：

1. 先把 `fetchers.py` 全文发给它（或拖文件）。
2. 说清楚："把 SOURCES 里 Nature 的 URL 换成《XXX》期刊的 RSS：……"
3. 拿到改完的代码后**自己核对 diff 再保存**——豆包偶尔会顺手重构无关代码。

## 提醒

- 豆包**不能**直接运行你电脑上的服务，"跑起来"这步它只能指导你操作（这一点是它和 WorkBuddy / TRAE 最大的差别）。
- **先把第 0 步的 10 个问题答完再让它动手** —— 尤其是学段与学制，没答清就会沿用作者的进度配置，进度卡会显示成"别人的博士进度"。
- 学生认证有会员额度，跑长任务比免费档稳。
